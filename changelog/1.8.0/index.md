# v1.8.0 — Shader GUI & Integration Update

### New Features

- Added clearer guidance for **Transparency Mask** using the Main Texture Alpha Channel
- Added **Documentation buttons** to individual features for quick access to the relevant documentation

### Improved Workflow

- Improved Shader GUI for **Mask Features** to reduce confusion and make settings easier to understand
- Improved the visual state of **Mask Texture** features to make their status more prominent and easier to identify
- Improved **Outline** and **Contact Shadow** compatibility with the upcoming ZLZ Env Shader

### Bug Fixes

- Fixed Additional Light passing through walls
