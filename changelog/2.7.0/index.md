# v2.7.0 — MatCap

**Latest version**

### New Features

- Added **[MatCap](/features/MatCap/)**: material look from a single sphere texture, with Add or Multiply blend
- Colors can be tuned with **Color** and **Hue**, so one texture can give several color variants
- Works with [Mask Layout](/features/#mask-layout-update-in-v-150)
